# evolving_landcover

Against irrigation_on, evolving land cover lowers the median NSE from 0.106 to 0.097 even though more gauges improve than degrade (547 better, 414 worse in NSE). Details: [Results](#results) (Configuration sensitivities).

## Evaluation run

- evolving_landcover: check_finidat_year_consistency=.false., because the restart year does not match the land-use year at the evaluation start. David Lawrence expected this to work with SP.

## Issues and fixes

- **Check build-namelist defaults.** Supplying flanduse_timeseries with a matching fsurdat turns irrigation on by default; preview_namelists shows it before the run.
- **Regional grids:** no default land-use time series exists for the NLDAS2 grid, and mksurfdata_esmf warns against regional grids (CTSM issue #2430). The evolving land-cover files were generated by Sean Swenson.
